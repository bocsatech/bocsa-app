# Áthelyezve → `bymy`

Ez a mappa **átköltözött**.

Az autós hirdetésfeladás weboldal most itt van:

```
~/Downloads/bymy          ← telepítés után (Mac)
~/bocsa-app/bymy          ← forrás a git repóban
```

**Telepítés + asztali indító:**

```bash
cd ~/bocsa-app/bymy/mac
chmod +x telepites.command
./telepites.command
```

Utána az asztalon: **Bymy-indito.command** → https://bymy.vercel.app
