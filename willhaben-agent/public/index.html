    Böngésző helper

    A szinkron a te Chrome ablakodban fut — a Willhaben saját munkameneteddel. Így nincs külön Playwright profil / zárolás.

    1. Chrome: chrome://extensions → Fejlesztői mód BE
    2. „Csomagolatlan bővítmény betöltése”
    3. Mappa: ~/Downloads/Willhaben Agent/browser-extension
    4. Nyisd meg a Willhaben chatet
    5. Nyomd meg a bal alsó ⇢ Agent szinkron gombot

    Alternatíva: Tampermonkey + browser-extension/willhaben-sync.user.js
