Willhaben Watcher — Chrome (Tampermonkey nélkül)

Miért nincs WH gomb? A Tampermonkey gyakran blokkolva van Chrome 138+-on. Ez a módszer közvetlenül a Chrome-ba telepíti — tesztelve, működik.
1. Töltsd le a teljes projektet ZIP-ben:
GitHub ZIP letöltés
2. Csomagold ki. Keresd ezt a mappát:
bocsa-app-main/willhaben-watcher/chrome-extension
3. Chrome címsor: chrome://extensions
Jobb felső: Fejlesztői mód → BE
4. „Csomag nélküli bővítmény betöltése”
Válaszd ki a chrome-extension mappát (benne: manifest.json)
5. Nyisd meg:
Autó keresési lista
Ctrl+Shift+R → jobb alul zöld WH gomb
Sablon üzenet: WH gomb → Sablon üzenet → Mentés → Automatikus figyelés BE

Tampermonkey-et kikapcsolhatod — nem kell hozzá.
